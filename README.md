# ⚙️ Industrial Automation, PLC & VFD Systems Portfolio

Comprehensive documentation of practical industrial control projects, motor drive programming, PLC ladder logic, and virtual plant commissioning.

---

## 📌 Practical Modules & Projects

### 1. Electric Motors & Variable Frequency Drives (VFD)
- **Drive Configuration & Commissioning:** Hands-on parameter tuning for multi-step speeds, jog operations, acceleration/deceleration ramp times, and electronic thermal overload protection.
- **Drives Handled:** Delta VFDs, INVT (Goodrive series), and Yaskawa industrial inverters.
- **Control Topologies:** Two-wire/three-wire terminal control, analog 0–10V / 4–20mA speed referencing, and dynamic braking resistor integration.

### 2. Classic Control & Motor Power Circuits
- **Motor Starting Schemes:** Direct-On-Line (DOL), Star-Delta starters, and forward/reverse interlocking configurations.
- **Protection Coordination:** Sizing thermal overload relays, circuit breakers (MPCB/MCCB), control transformers, and auxiliary contactors.
- **Sequential Logic:** Timer-based sequence control, automatic pump alternation, and fault-signaling logic.

### 3. PLC Programming & Logic Simulation (Siemens TIA Portal)
- **Programming Languages:** Ladder Diagram (LAD) and Function Block Diagram (FBD).
- **Core Automation Logic:** Timers (TON, TOF, TP), up/down counters, memory flags, and mathematical comparisons.
- **Simulation & Testing:** Offline commissioning and logic verification using **S7-PLCSIM**.

### 4. 3D Factory Simulation (Factory I/O)
- Virtual plant integration pairing PLC logic with real-time 3D physics engines.
- Projects include automated conveyor sorting lines, tank level controls, and palletizer machines.
